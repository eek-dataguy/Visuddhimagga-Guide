## 🌟 មុខងារចម្បងៗក្នុងកម្មវិធី (Key Features)

### ១. ឧបករណ៍ជំនួយគណនាវិធី និងកំណត់សតិ (Interactive Breathing & Gaṇanā Tool)
- **Breathing Orb & Counter**: ចលនាដង្ហើមចូល-ចេញ ស្របតាមចង្វាក់ដកដង្ហើម ជាមួយនឹងការរាប់លេខពី ១ ដល់ ៥ និង ១០។
- **គណនាវិធី ២ របៀប**:
  - *វិធីរាប់យឺត (ដូចវាល់អង្ករ)*: ដកដង្ហើមចូល-ចេញរួចទើបរាប់ ១...
  - *វិធីរាប់លឿន (ដូចគោបាល)*: ដកចូល ១ ចេញ ១, ដកចូល ២ ចេញ ២...
- **ផុសនស្ថាន (Touch-point Anchoring)**:
  - ចុងច្រមុះ (*នាសិកគ្គ*) សម្រាប់មនុស្សច្រមុះវែង
  - បបូរមាត់លើ (*ឧត្តរោដ្ឋ*) សម្រាប់មនុស្សច្រមុះខ្លី
- **សំឡេងជួងកណ្តឹងសមាធិ (Tibetan Bowl / Gong Synthesizer)**: បង្កើតសំឡេងដោយផ្ទាល់តាមរយៈ Web Audio API ដោយមិនបាច់ទាញយក file សំឡេងពីក្រៅ និងដំណើរការបាន ១០០% offline។

### ២. ការកាត់បលិពោធ ១០ ប្រការ (Severing the 10 Palibodha)
- បញ្ជីពិនិត្យកាត់កង្វល់ប្រចាំថ្ងៃ (អាវាស ត្រកូល លាភ គណៈ ការងារ អទ្ធាន ញាតិ អាពាធ គន្ថ ឫទ្ធិ) មុនពេលអង្គុយភាវនា ភ្ជាប់ link ទៅកាន់ទំព័រពន្យល់ផ្ទាល់ក្នុង `tripitaka82.com`។

### ៣. ចតុរារក្ខ / សព្វត្ថកកម្មដ្ឋាន (The 4 Protective Meditations)
- កម្មដ្ឋានការពារចិត្ត ៥ នាទីមុនចូលកម្មដ្ឋានចម្បង៖ ពុទ្ធានុស្សតិ, មេត្តាភាវនា, មរណស្សតិ, អសុភសញ្ញា។

### ៤. ប្រព័ន្ធវិនិច្ឆ័យចរិត ៦ (Carita Diagnostic Engine)
- សំណួរវិភាគចំនួន ៦ ផ្អែកលើឥរិយាបថដើរ ការធ្វើការងារ ចំណង់អាហារ បរិយាកាសបន្ទប់ ការគេង និងប្រតិកម្មអារម្មណ៍។
- ផ្តល់នូវលទ្ធផលចរិតលេចធ្លោ កម្មដ្ឋានចម្បងដែលត្រូវនឹងនិស្ស័យ (*Pārihāriya*), ឱវាទក្នុងវិសុទ្ធិមគ្គ និងសប្បាយ ៧ យ៉ាង។

### ៥. ផែនទីការប្រតិបត្តិ ៤ ដំណាក់កាល (4-Stage Progressive Curriculum)
- **ដំណាក់កាលទី ១៖ អាទិកម្មិកបុគ្គល (Beginner)**: សីល, កាត់បលិពោធ, ចតុរារក្ខ, គណនាវិធី ៥-១០។
- **ដំណាក់កាលទី ២៖ យោគាវចរមធ្យម (Intermediate)**: អនុពន្ធនា, ផុសនា, កម្ចាត់នីវរណៈ ៥, កត់សម្គាល់និមិត្ត (បរិកម្ម, ឧគ្គហ, បដិភាគនិមិត្ត), អប្បនាកោសល្យ ១០។
- **ដំណាក់កាលទី ៣៖ ឈានលាភី (Advanced / Absorption)**: បឋមជ្ឈាន (អង្គ ៥), វសី ៥ (អាវជ្ជន, សមាបជ្ជន, អធិដ្ឋាន, វុដ្ឋាន, បច្ចវេក្ខណៈ), ទុតិយជ្ឈាន ដល់ ចតុត្ថជ្ឈាន។
- **ដំណាក់កាលទី ៤៖ បរមយោគី / អ្នកស្ទាត់ជំនាញ (Expert / Master)**: អរូបជ្ឈាន ៤, ចតុធាតុវវដ្ឋាន, សមាធិជាបាទគ្រឹះនៃវិបស្សនា។

### ៦. សព្វវចនានុក្រមកម្មដ្ឋាន ៤០ (40 Kammaṭṭhāna Catalog)

### ៧. ឱសថធម៌កម្ចាត់នីវរណៈ ៥ (Nīvaraṇa Antidotes)
